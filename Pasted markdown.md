## Recent Work & Learning

### Agent Systems

I’m working on **AgentFlow**, an experimental agent execution framework focused on:

- running agents locally
- tracking changed files through Git diffs
- storing execution results
- rendering dashboards
- ranking candidate outputs
- supporting different execution profiles like `strict`, `default`, and `debug`

The goal is to understand how real-world coding agents behave when they are asked to implement features, run tests, fix bugs, and iterate toward a correct solution.

---

### LLM Evaluation

I’ve been exploring how to evaluate LLMs beyond simple prompt testing.

Recent focus areas:

- building eval pipelines with **promptfoo**
- testing local models through **llama.cpp endpoints**
- validating structured JSON outputs
- designing task-based evals
- ranking outputs based on correctness, test results, and execution behavior

I’m especially interested in eval systems that measure how well an AI agent can solve engineering tasks, not just answer questions.

---

### FrontierSWE-Style Benchmarking

I’m interested in contributing to benchmark design for software engineering agents.

The idea I’m exploring:

> Give an agent a real engineering feature, let it implement, test, debug, and iterate — then measure how many iterations it takes to reach the expected solution.

This includes comparing behavior across:

- low-reasoning tasks
- medium-reasoning tasks
- high-reasoning tasks
- sequential agents
- parallel agent harnesses
- real-world repository workflows

### Reinforcement Learning

I’ve been learning classic RL by building and explaining concepts from first principles.

Topics I’ve worked through:

- Markov Decision Processes
- Bellman Equations
- Dynamic Programming
- Monte Carlo methods
- SARSA
- Q-Learning
- policy/value iteration

I’m also building a fun RL project:

### Catch Me If You Can

A small RL environment where:

- a character learns to run away
- the player tries to catch it using hand gestures
- the live system uses **OpenCV** and **MediaPipe**
- the agent is first trained in a simulated coordinate-based environment

The goal is to bridge simulated RL with simple real-time interaction.
